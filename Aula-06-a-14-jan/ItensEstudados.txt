Qual o método que inicia a execução no JAVA?
R-> public static void main, que é o método principal que inicia a execução.

O que é uma Classe?
R-> É onde definimos os atributos e métodos do objeto que estamos construindo.

Como criar uma Classe?
R-> Usando o public class + nome da classe (mesmo nome do arquivo, iniciando com a letra maiúscula).

O que é um Método?
R-> São como funções que definem os comportamentos possíveis de uma classe.

O que é uma variável?
R-> É um espaço reservado na memória para armazenar um valor.

O que é uma condicional (comando if)?
R-> É uma estrutura que executa uma ação com base em uma condição.

O que é Herança?
R-> Herança é quando uma classe herda os atributos e métodos de outra classe. Para isso, ela precisa ser estendida, assim fica “visível”.

Como comparar String?
R-> Usando equals().

Como receber dados do usuário pelo console?
R-> Usando Scanner, precisamos fazer a importação: import java.util.Scanner

Por que tivemos que migrar do Java 1 para o Java 17?
R-> Para usufruir de novos recursos, no nosso caso o Scanner, que só surgiu no Java 8.

O que é compilar?
R-> É traduzir o código Java para bytecode.

O que é executar?
R-> É rodar o bytecode na JVM.

O que é erro de compilação?
R-> Erro interceptado pelo compilador antes de rodar o programa.

O que é erro de execução?
R-> Erro que acontece enquanto o programa está rodando.

Como usar herança no Java?
R-> Usando extends.

Como concatenar String?
R-> Usando +.
